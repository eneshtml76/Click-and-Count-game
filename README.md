# 🎯 Click-and-Count

Hello! This is my Click-and-Count game project.

I made this game using **HTML, CSS, and JavaScript** while learning web development.

The idea of the game is simple:
Count the circles, enter the correct number, and try to get the highest score!

---

## 🎮 Features

- Random circles every round
- 30 second timer
- Score system
- High score saving
- Press Enter to check answers
- Simple animations
- Button hover effects

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

---

## 📖 What I Learned

While making this project, I learned:

- How to use JavaScript with HTML
- How to change elements with DOM
- How buttons and events work
- How to create random numbers
- How to use functions and loops
- How to save data with Local Storage

---

## 🎮 How To Play

1. Click the "Start Game" button
2. Count the circles
3. Write your answer
4. Click "Check Answer" or press Enter
5. Try to make a new high score!
